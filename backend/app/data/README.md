# Transport reference data

These datasets are bundled so route layers need no upstream requests at runtime. Rebuild with `/usr/bin/python3 backend/scripts/build_transport_data.py` from the repository root. The script pins both upstream commits; rebuilding intentionally requires outbound access.

- `air-routes.geojson`: OpenFlights direct airline connections from the June 2014 route snapshot, joined to airport coordinates at commit `7d1a611e070295dba776d6afb86e57d0d1aa1cef`. Geo combines directions/codeshares, ranks airport pairs by distinct airline count, and includes the top 2,000 pairs. This is a selected global overview, not a complete network or current flight schedule. The response reports the full resolved connection count and selection rule. Great-circle arcs use steps of at most 4 degrees and four decimal coordinate precision, and split at the date line. Source: https://openflights.org/data. Derived database available under ODbL 1.0; contents under Database Contents License 1.0. See `openflights-LICENSE.txt` for license links. The upstream application software's AGPL license does not describe these database files.
- `sea-routes.geojson`: P. Benden's Global Shipping Lanes at commit `b0ad85cdab959b84bc915b21d77d18bb8f1429f4`. Digitized from a CIA October 2012 world-oceans map and published as a dataset in 2022. Contains Major/Middle/Minor schematic corridors; neither AIS observations nor contemporary sailing schedules. Geo rounds coordinates to four decimals and splits lines at the date line. Source: https://github.com/newzealandpaul/Shipping-Lanes. Citation: Benden, P. (2022), Global Shipping Lanes, https://doi.org/10.5281/zenodo.6361763. The supplied LICENSE is a custom CC Attribution 4.0 license excluding Statista (despite inconsistent ShareAlike wording in the upstream README); retain `shipping-lanes-LICENSE.txt` when redistributing.

Both products are reference maps, not for navigation. Source vintages are displayed independently of the time Geo serves the files. API endpoints expose the same transformed data for download, with attribution and source links.
